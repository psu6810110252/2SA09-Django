# UncleShop - Django Backend REST API

## 📂 โครงสร้างสถาปัตยกรรมระบบ (Modular Architecture)
โปรเจกต์ถูกออกแบบโครงสร้างแบบแยกขอบเขตงาน (Separation of Concerns) ออกเป็น 4 โมดูลหลัก:
* `accounts`: จัดการระบบผู้ใช้งาน, การยืนยันสิทธิ์ด้วย Token Authentication (`AuthToken`), และข้อมูลโปรไฟล์ผู้ใช้
* `shop`: จัดการข้อมูลสินค้า (`Product`), ระบบอัปโหลดสื่อรูปภาพ (`Media Handling`), และ REST API สำหรับแคตตาล็อกสินค้า
* `cart`: ระบบจัดการตะกร้าสินค้า
* `orders`: ระบบจัดการคำสั่งซื้อและการออกใบสั่งซื้อ

## 🍱 ชุดข้อมูลสินค้า (Custom Dataset)
ระบบได้รับการปรับเปลี่ยนชุดข้อมูลเริ่มต้นให้เป็น **หมวดหมู่ขนมหวานและเครื่องดื่มสไตล์ญี่ปุ่น (Japanese Desserts & Beverages)** รวม 6 รายการ ผ่าน 2 กระบวนการ:
1. **Automated Seeding via Script (`Sushi.py`):** นำเข้าข้อมูลขนมหวานญี่ปุ่น 4 รายการลงฐานข้อมูลอัตโนมัติ
   * ไดฟุกุสตรอว์เบอร์รี (45.00 บาท)
   * มิตาราชิดังโงะ (35.00 บาท)
   * โดรายากิ (40.00 บาท)
   * ไทยากิไส้คัสตาร์ด (30.00 บาท)
2. **Manual Input via Django Admin:** นำเข้าข้อมูลเครื่องดื่มญี่ปุ่น 2 รายการผ่านหน้าจอควบคุมของผู้ดูแลระบบ
   * มัทฉะลาเต้เย็น (65.00 บาท)
   * รามูเนะ น้ำอัดลมญี่ปุ่น (50.00 บาท)
